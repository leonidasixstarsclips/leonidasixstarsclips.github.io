Who we are

SixStarsClips is a fan-run YouTube channel and the internal software tool used to manage it (the “Application”). Contact for any privacy request: leonidasixstarsclips@gmail.com.

Who uses the Application

The Application is used exclusively by the owner of the SixStarsClips channel to manage that channel. It offers no sign-in or services to anyone else and does not access other people's Google accounts.

Google data accessed by the Application

Through the YouTube API Services, with the authorization of the channel owner's account, the Application uses these scopes:

  • youtube.upload: to upload the weekly videos and Shorts to the owner's channel;
  • youtube.force-ssl: to set thumbnails, post a comment on the channel's own videos, check the status of the channel's videos and read the public comments on them.

Viewer comments

To see which clips viewers liked most, the Application reads the public comments on SixStarsClips videos: comment text, date and the author's public YouTube channel ID. The channel ID is used only to count one preference per person. Comments are processed at counting time and are not stored; only aggregate totals per clip are kept (numbers, no personal data).

Twitch data

The Application uses the public Twitch API to retrieve public GTA 6 clips, with their public metadata (title, channel name, views, duration, language). The streamer's name and Twitch link are shown in videos and descriptions as credit. The Application keeps a record of which streamers' clips were used in which videos, and a list of streamers who asked not to be featured, so their requests are honored.

Storage and security

The Google authorization token and operational data (clip list, publishing status, aggregate totals) are stored only on the owner's private server on a local network, not reachable from the internet. Source clips are deleted after a few weeks.

Sharing

No data is sold, transferred or shared with third parties, or used for advertising, profiling or training models.

SixStarsClips' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The Application uses the YouTube API Services. By interacting with SixStarsClips videos you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

The channel owner can revoke the Application's access at any time from Google Account third-party connections.

Your rights

You can contact us to learn what data we process, to request deletion or, if you are a streamer, to have your clips removed and never used again. You can delete your YouTube comments at any time; deleted comments are no longer counted.

Changes

Updates to this policy are published on this page with a new “last updated” date.

Sintesi in italiano

SixStarsClips è un canale YouTube di fan. Il suo strumento interno è usato solo dal proprietario del canale e, tramite i servizi API di YouTube, carica video e Short sul suo canale (youtube.upload), imposta le miniature, pubblica un commento e legge i commenti pubblici dei video del canale (youtube.force-ssl). I commenti non vengono archiviati: si conservano solo totali aggregati. I dati restano su un server privato in rete locale, non vengono venduti né condivisi. L'uso dei dati ricevuti dalle API di Google rispetta la Google API Services User Data Policy, inclusi i requisiti di Uso limitato. Contatto: leonidasixstarsclips@gmail.com.
